# Configuration examples

Copy the one that matches your client. Full instructions are in
[../QUICKSTART.md](../QUICKSTART.md).

| File | Goes in |
| --- | --- |
| `cursor-mcp.json` | `.cursor/mcp.json` in a project, or `~/.cursor/mcp.json` for every project |
| `vscode-mcp.json` | `.vscode/mcp.json` in a workspace |
| `claude-code.sh` | Run it. Nothing to place. |

Claude on the web and desktop needs no file: add a custom connector pointing at
`https://sunago-matrix.com/mcp`.
